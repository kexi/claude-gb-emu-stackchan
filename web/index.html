ゲームパッド

🎮 USB / Bluetooth ゲームパッド対応 (Gamepad API)。接続して何かボタンを押すと認識されます。

セーブ

バッテリーバックアップ付きカートリッジのセーブデータはブラウザ (localStorage) に自動保存されます。

FM拡張

FM ボタンで ModRetro Chromatic の FM 音源拡張 (YM2151 + ADPCM、$FF28-$FF2F) を有効化。対応 ROM 専用です。
